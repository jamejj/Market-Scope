## Sygnały ostrzegawcze

Zaznacz, jeśli wystąpiło:

- Tester nie wie, gdzie zacząć.
- Tester nie znajduje `Rynek`.
- Tester nie rozumie różnicy między `Sygnały` i `Rynek`.
- Tester myli `Obserwacje` z transakcjami.
- Tester myli `Forward Proof` z realnym portfelem.
- Tester nie rozumie `FAST`.
- Tester nie rozumie `ML`.
- Tester nie rozumie `Proof`.
- Tester nie rozumie `P(wzrost)`.
- Tester nie rozumie `expected return / oczekiwany ruch`.
- Tester nie znajduje metodologii.
- Tester uważa, że aplikacja mówi „kup”.

## Pytania po każdym zadaniu

- Co Twoim zdaniem aplikacja właśnie powiedziała?
- Jak pewny wydaje Ci się ten wniosek?
- Co kliknąłbyś dalej?
- Czy czegoś Ci brakowało?

## Klasyfikacja problemów

P0 — blokujące:

- Użytkownik interpretuje aplikację jako bezpośrednią rekomendację transakcji.
- Nie potrafi wykonać głównej ścieżki.
- Produkt gubi kontekst symbolu lub pokazuje mylące dane.

P1 — ważne:

- Użytkownik wykonał zadanie, ale z dużym wahaniem.
- Terminologia wymagała wyjaśnienia.
- Właściwa funkcja była znaleziona, ale nieintuicyjnie.

P2 — polish:

- Estetyka, długość tekstu, drobne nazwy, kolejność elementów.
